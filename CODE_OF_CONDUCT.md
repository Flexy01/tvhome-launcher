# Code of conduct

This project exists because a few thousand people helped each other fix their TVs in the replies
to a tweet. Keep it like that.

## Expected

- Be kind. Many contributors are doing this on a parent's or grandparent's TV, in a second
  language, on their first pull request.
- Assume good faith. A list that breaks something was tested on different firmware, not written to
  hurt anyone.
- Say what you tested on. Specifics ("Android TV 11, build RTT1, Hisense A4") help; verdicts
  ("doesn't work") do not.
- Respect the maintainers' decisions on scope. The launcher stays small, offline and without
  prebuilt binaries; if your idea does not fit, a fork with a SHOWCASE row is a good outcome, not a
  rejection of you.

## Not accepted

- Insults, harassment, slurs, sexualised language or imagery, or personal attacks, in issues,
  pull requests, Discussions or the showcase.
- Publishing other people's private information: device identifiers, Wi-Fi names, IP addresses,
  ADB keys or anything that could identify a TV or a home.
- Lists or instructions that uninstall, root, or intentionally damage a TV, or that target a
  specific person's device.
- Spam, affiliate links, or passing off someone else's work as your own.

## Reporting a Violation

To protect the safety and privacy of everyone involved, **never report code of conduct violations through public GitHub issues, pull requests, or public discussions**. Public reports expose complainants and respondents to unwanted attention, retaliation, and risk disclosing sensitive personal data.

### How to Report

If you experience or witness unacceptable behavior, harassment, or a violation of this code, send a private report to the project maintainers:

- **Email:** `tvhomelauncher@gmail.com`

Please include the following details to help maintainers review and resolve the situation:
- Date, approximate time, and location of the incident (link to issue, PR, comment, or commit).
- Identity of the individuals involved.
- A factual description of the behavior observed and why it violates this code.
- Any relevant context or unredacted screenshots.

If an incident involves a maintainer, you may state this clearly in your report so it is reviewed by other project administrators.

### Confidentiality & Privacy

Maintainers will handle all reports in confidence within the moderation team and will not disclose identifying details publicly without the reporter's explicit consent.

Please note that standard email is not cryptographically anonymous or end-to-end encrypted; maintainers promise procedural confidentiality, not technical anonymity. If you wish to protect your identity, you may use an alternative email address that does not reveal personal details.

### Separation from Security Vulnerabilities

Software vulnerabilities, code injection risks, or ADB security defects must **not** be reported here; report technical vulnerabilities privately through the process described in [`SECURITY.md`](SECURITY.md). Conversely, interpersonal conduct and harassment complaints must not be submitted through GitHub Security Advisories.

## Enforcement

Maintainers are responsible for clarifying and enforcing our standards of acceptable behavior. When a violation occurs, maintainers will review the incident and take fair, proportional action:

1. **Correction:** A private explanation pointing out why the behavior was unacceptable, with a request for voluntary correction or removal.
2. **Warning:** A formal warning with specific consequences if the behavior continues.
3. **Temporary Suspension:** A temporary restriction from interacting with the repository (comments, issues, PRs) for a specified duration.
4. **Permanent Ban:** A permanent block from the repository and community spaces for severe or repeated violations (such as intentional harassment, hate speech, or malicious doxxing).

Maintainers may also edit, hide, or delete any comment, issue, or pull request that violates these standards.

This is a short, plain-language code adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
